Website und Hosting

Diese Hinweise gelten für cc-picker.brue.nu. Die statische Website wird auf unserem VPS bei Netcup in Deutschland bereitgestellt. Für die Übertragung verarbeitet der Server technisch notwendige Verbindungs- und Anfragedaten, insbesondere IP-Adresse, Zeitpunkt, angefragte Adresse und vom Browser übermittelte Angaben. Das dient der Auslieferung, Sicherheit und Fehlerbehebung.

In unserer Caddy-Konfiguration ist kein gesondertes HTTP-Zugriffsprotokoll aktiviert. Technische Betriebs- und Fehlerprotokolle können dennoch Verbindungsdaten enthalten. Eine feste Löschfrist ist dafür derzeit nicht konfiguriert; die Speicherung wird durch die Protokollrotation und die verfügbaren Speichergrenzen bestimmt. Das bedeutet nicht, dass keinerlei Daten beim Hostinganbieter anfallen.

Analyse, Schriften und Browserspeicher

Diese Website bindet weder Matomo noch andere Besucheranalysedienste ein. Es werden keine Analyse-Cookies gesetzt. Schriften, Bilder und Skripte werden von dieser Website geladen; Google Fonts wird nicht kontaktiert.

Im localStorage deines Browsers speichern wir ausschließlich cc-lang (Sprache) und cc-level (einfacher oder technischer Text). Diese Werte werden nicht an uns übertragen. Sie bleiben ohne feste Ablaufzeit gespeichert, bis du die Websitedaten im Browser löschst. Bei gesperrtem Browserspeicher funktioniert die Seite weiterhin; die Auswahl wird dann nicht dauerhaft behalten.

Links, Werkzeug und Kontakt

GitHub wird erst beim Öffnen eines entsprechenden Links aufgerufen; dort gelten die Datenschutzhinweise von GitHub. Die hier gezeigte Demo startet keine Programme und überträgt keine Projektdateien.

Das heruntergeladene Werkzeug cc-picker speichert Einstellungen und Projektverlauf lokal. Optionales Git-Klonen, das Nachinstallieren von Paketen und das gestartete Claude Code können Netzwerkverbindungen herstellen. Insbesondere unterliegt Claude Code den Bedingungen und Datenschutzhinweisen seines Anbieters. Der gewählte Arbeitsordner ist keine Sicherheitsgrenze.

Wenn du uns per E-Mail kontaktierst, bearbeiten wir deine Nachricht und Kontaktdaten zur Beantwortung. Sende keine Passwörter, Tokens oder vertraulichen Projektdateien.
