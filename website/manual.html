Anleitung / Loslegen

In wenigen Schritten startklar.

Du brauchst Linux und eine funktionierende Claude-Code-Installation. cc-picker hilft dir, Claude im passenden Projektordner zu starten.

1

Einmal installieren

Öffne ein Terminal und führe diese beiden Zeilen nacheinander aus.

Fehlt die Fensterunterstützung, bietet der Installer ihre Installation an – mit vorheriger Befehlsanzeige und nur nach deiner Zustimmung. Ohne Installation bleibt das Terminal-Menü verfügbar.

$ git clone https://github.com/bruneler/cc-picker.git
$ cd cc-picker && ./install.sh
2

cc-picker öffnen

Suche in deinem Anwendungsmenü nach „cc-picker“. Alternativ gibst du cc-picker im Terminal ein.

3

Dein erstes Projekt wählen

Wähle einen vorhandenen Ordner aus der Liste oder „+ Neues Projekt erstellen“. Claude Code startet direkt dort.

Deine Projekte liegen standardmäßig im Ordner ~/claude-projects. Weitere Projektordner lassen sich einstellen.
Was wird installiert? · Technische Details

Der Starter, ein Eintrag im Anwendungsmenü und das Icon werden in deinem Benutzerverzeichnis eingerichtet. Fehlt ein Dialogprogramm, bietet der Installer unter KDE kdialog und sonst zenity an. Er zeigt den genauen Installationsbefehl und führt ihn nur nach deiner Zustimmung aus. Bei abgelehnter oder fehlgeschlagener Installation bleibt das Terminal-Menü verfügbar. Ohne interaktives Terminal oder mit CC_PICKER_NO_DEPS=1 wird nicht nachgefragt. Bei unbekanntem Paketmanager erscheint ein Hinweis zur manuellen Installation.

Anleitung / Projekte auswählen

Das richtige Projekt. Ohne Suchen.

Zuletzt verwendete Projekte stehen weit oben. Angeheftete Favoriten bleiben ganz vorne.

1

Auswählen und starten

Im Fenster wählst du ein Projekt und klickst auf „Starten“. Im Terminal-Menü gibst du seine Nummer ein.

2

Die Liste eingrenzen

Im Terminal genügt ein Teil des Namens. Im Fenster erscheint die Suche ab acht Projekten.

3

Direkt zum letzten Projekt

Mit diesem kurzen Befehl öffnest du das zuletzt verwendete Projekt:

$ cc-picker -
Direktstart und Suchwerkzeuge · Technische Details

cc-picker NAME akzeptiert einen eindeutigen Namensanfang. Ist fzf installiert, übernimmt es die Suche im Terminal. Mit CC_PICKER_FZF=0 verwendest du das normale Menü.

Anleitung / Neu anlegen & klonen

Eine gute Idee braucht einen Ordner.

Starte leer, mit einer Vorlage oder mit einem Projekt, das bereits online liegt.

1

„Neues Projekt erstellen“ wählen

Gib deinem Projekt einen Namen. Ein bereits vorhandener Projektordner wird dabei nicht überschrieben.

2

Neu anfangen oder herunterladen

Füge eine Git-Adresse ein, um ein Repository zu klonen. Für ein neues Projekt lässt du das Feld leer.

3

Bei Bedarf eine Vorlage wählen

Die mitgelieferte Standardvorlage enthält eine Datei für Projekthinweise an Claude und eine Git-Ausschlussliste. Du kannst auch einen leeren Ordner wählen.

Eigene Vorlagen · Technische Details

Vorlagen liegen unter ~/.config/cc-picker/templates/. Der Platzhalter {{PROJECT_NAME}} wird durch den Namen ersetzt. Bei Vorlagen wird außerdem git init ausgeführt. Für GitHub genügt beim Klonen benutzer/repo.

Anleitung / Sitzungen fortsetzen

Da weitermachen, wo du warst.

Wenn Claude Code für dein Projekt frühere Sitzungen gespeichert hat, bietet cc-picker dir drei Möglichkeiten.

1

Neu anfangen

Starte eine neue Unterhaltung im gleichen Projektordner.

2

Letzte Sitzung fortsetzen

Knüpfe direkt an deine letzte Unterhaltung an.

3

Frühere Sitzung auswählen

Öffne die Sitzungsauswahl von Claude Code, um einen älteren Gesprächsverlauf fortzusetzen.

Auswahl per Befehl · Technische Details

Nutze -n für neu, -c zum Fortsetzen oder -r für die Auswahl. Beispiel: cc-picker -c mein-projekt. Mit CC_PICKER_SESSION lässt sich ein Standard festlegen.

Anleitung / Ordnung halten

Weniger Stapel. Mehr Überblick.

Über „Projekte verwalten“ hältst du deine Liste übersichtlich, ohne deine Arbeit zu verlieren.

1

Wichtiges anheften

Favoriten stehen vor den zuletzt verwendeten Projekten. Du kannst Projekte auch direkt im Editor oder Dateimanager öffnen.

2

Fertige Projekte archivieren

Archivierte Ordner verschwinden aus der normalen Liste. Sie bleiben erhalten und lassen sich später wiederherstellen.

Beim Umbenennen ändert sich der Ordnerpfad. Claude Code kann bisherige Sitzungen deshalb unter dem neuen Namen nicht wie zuvor fortsetzen.
Mehrere Projektordner · Technische Details

In ~/.config/cc-picker/config kannst du beispielsweise CC_PICKER_BASE=~/claude-projects:~/code setzen. Neue Projekte landen im ersten Ordner. Das Archiv liegt jeweils unter .archive/.

Anleitung / Updates & Hilfe

Aktuell bleiben. Einfach weiterkommen.

Ein Befehl holt die neueste veröffentlichte Version. Einstellungen und Projektliste bleiben erhalten.

$ cc-picker --update
Es erscheint kein Fenster

Die grafische Auswahl benötigt zenity, kdialog oder yad. Fehlt ein solches Programm, bietet der Installer dessen Installation an: unter KDE kdialog, sonst zenity. Er zeigt den Befehl und fragt nach deiner Zustimmung. Du kannst ./install.sh im heruntergeladenen cc-picker-Ordner erneut ausführen. Lehnst du ab oder bleibt die Installation erfolglos, verwendet cc-picker das Terminal-Menü. Beim normalen Start wird nicht erneut nachgefragt. Du kannst es mit cc-picker --shell-mode direkt öffnen.

Mein Projekt fehlt in der Liste

Prüfe, ob der Ordner in einem eingestellten Projektverzeichnis liegt. Versteckte Ordner werden nicht angezeigt. Ein Archiv lässt sich über die Projektverwaltung öffnen.

Ich möchte einen Fehler melden

Hilfreich sind die Ausgabe von cc-picker --version, deine Linux-Distribution und die Schritte bis zum Fehler. Sicherheitslücken bitte privat über den Meldeweg in SECURITY.md melden.

cc-picker wählt den Arbeitsordner. Welche Dateien Claude Code darüber hinaus lesen oder ändern darf, bestimmen dessen eigene Berechtigungen.
